# Intro Page

This folder contains the complete editable intro page:

- `IntroPage.jsx` — React host and iframe integration.
- `IntroPage.css` — responsive host sizing.
- `page.config.js` — intro title and accessible page label.
- `IntroDocument.html` — page markup, five theme styles, copy and its local JavaScript.

Edit `IntroDocument.html` to change the introduction page's wording, layout, and visual design. The intro theme selector cycles Black & White, Orange & White, Red & White, Neon Yellow & White and Neon Red & White. Its selection is synchronized with the React host through a theme event.
